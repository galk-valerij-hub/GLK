# Страница целиком → PDF

Расширение Google Chrome для сохранения длинных страниц и широких досок в один PDF. Создано для сценариев вроде карточек CRM и канбанов, которые не помещаются на экране.

**Статус: экспериментальная версия 1.1.0.** Сборка проверена на тестовой области 2400 × 1800 px. Полнота захвата последней версии на реальных карточках Битрикс24 пока не подтверждена.

## Что делает

- Прокручивает выбранную область вниз и вправо и собирает снимки в один большой PDF.
- Пытается выбрать видимую вложенную рамку карточки, чтобы не захватывать фон за ней.
- Не меняет CSS, размеры блоков и слои страницы; после завершения возвращает исходную прокрутку.
- Сохраняет файл в `Page PDF` внутри папки загрузок Chrome.
- Работает локально: в коде нет отправки снимков на сервер, аналитики или внешних библиотек.

PDF растровый: текст в нём нельзя искать или копировать как обычный текст. Формат рассчитан на просмотр и увеличение, а не на печать на листах A4.

## Установка в Chrome

1. Нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку **GLK-main**, где находится `manifest.json`.
5. В `chrome://extensions/shortcuts` проверьте горячую клавишу:
   - macOS: **Command + Shift + Y**;
   - Windows/Linux: **Ctrl + Shift + Y**.

Расширение не опубликовано в Chrome Web Store. Устанавливайте его только после ознакомления с кодом и разрешениями.

## Как пользоваться

Откройте нужную страницу, дождитесь загрузки и нажмите кнопку расширения или горячую клавишу. Пока идёт захват, оставьте вкладку активной и не прокручивайте её вручную.

На кнопке отображается количество снятых участков. **OK** означает, что PDF передан в загрузки. При ошибке откроется отдельная вкладка с точным текстом причины.

## Print Screen на Mac

Для отдельной клавиши Print Screen нужен установленный **Karabiner-Elements**. Без него доступны кнопка расширения и Command + Shift + Y.

1. Скопируйте `Print-Screen-Karabiner.json` из репозитория в `~/.config/karabiner/assets/complex_modifications/`.
2. В Karabiner-Elements откройте **Complex Modifications → Add predefined rule** (название пункта зависит от версии).
3. Включите правило **Print Screen → сохранить всю страницу Chrome в PDF**.

Правило действует только в Google Chrome. Не заменяйте им целиком свой `karabiner.json` — это файл отдельного правила. Если клавиатура отправляет другую клавишу вместо `print_screen`, её код можно проверить в Karabiner-EventViewer.

## Ограничения

- Виртуализированные списки, подгружаемые данные и несколько независимых областей прокрутки могут захватываться неполностью. Основная область выбирается автоматически.
- Закреплённые панели могут повторяться на снимках. При захвате внутренней области внешние панели и заголовок могут не входить в PDF.
- Закрытые разделы не раскрываются, кнопки «Загрузить ещё» не нажимаются.
- Рамки другого сайта могут быть недоступны из-за разрешений. В таком случае попробуйте открыть нужную карточку в отдельной вкладке.
- Лимит: 160 снимков на один PDF. Для очень больших страниц можно уменьшить масштаб Chrome.
- Захват прерывается, если вкладка перестаёт быть активной.
- Служебные страницы Chrome, Chrome Web Store и страницы с ограничением захвата не поддерживаются.

## Разрешения и конфиденциальность

| Разрешение | Зачем нужно |
| --- | --- |
| `activeTab` | Доступ к выбранной вкладке после запуска пользователем |
| `scripting` | Определение области прокрутки и перемещение по ней |
| `debugger` | Снимки видимых участков через Chrome DevTools Protocol |
| `downloads` | Сохранение готового PDF |

`debugger` — широкое разрешение, позволяющее читать и управлять вкладкой. В этой версии подключение выполняется после запуска захвата и отключается в блоке завершения. Chrome может показывать информационную панель отладки. Перед захватом закройте DevTools, если они конфликтуют с подключением.

PDF может содержать конфиденциальные данные самой страницы. Проверяйте его содержимое перед отправкой другим людям.

## Обновление и удаление

Для обновления замените файлы в установленной папке и нажмите **Обновить ↻** на карточке расширения в `chrome://extensions`.

Для удаления удалите расширение в Chrome. Если включали Print Screen через Karabiner, отдельно отключите это правило.

## Что проверено

На искусственной доске 2400 × 1800 px девять участков собраны в PDF; визуальная проверка подтвердила расположение всех шести рядов и колонок. DOM, стили и положение прокрутки после захвата остались прежними. Это не является подтверждением совместимости со всеми сайтами.
